# Aruco_Slam

Aruco SLAM with ROS 

Localisation ability is a prerequisite for the realisation of autonomous systems. In this paper, the extended Kalman filter is used to fuse the encoder information with the information of the camera fiducial markers detection and realise the SLAM algorithm. A new observation model is used considering both the position and orientation of the fiducial markers. The algorithm is implemented using robot operating system and tested in simulation and real environments. The test results show that the algorithm can achieve the expected result, and prove that multi-information fusion has a better effect than single-sensor positioning.

Liang, Y., Stancu, A., & Zhang, Z. (2023, August). Simultaneous localisation and mapping with fiducial markers based on extended Kalman filter. In 2023 6th International Conference on Intelligent Robotics and Control Engineering (IRCE) (pp. 154-162). IEEE.
